O projektu Gaming World

Web věnovaný počítačovým a konzolovým hrám, hernímu vybavení a komunitě hráčů.

Cíl webu

Gaming World představuje herní svět přehlednou a srozumitelnou formou. Návštěvníci zde najdou informace o herních žánrech, oblíbených titulech, vybavení a zajímavostech spojených s hraním.

Web je vytvořen jako studentský projekt s využitím HTML, CSS, JavaScriptu a frameworku Bootstrap 5. Rozložení stránek je přizpůsobeno také mobilním zařízením.

Co zde najdeš?

  • Galerii herního prostředí

  • Herní dotazník

Poznej Gaming World

Herní žánry a tituly

Mezi oblíbené herní žánry patří akční hry, RPG, strategie, simulátory a závodní hry. Každý nabízí jiný typ zážitku a způsob hraní.

Prohlédnout hry

Hraní s ostatními

Herní komunita umožňuje sdílet zkušenosti, spolupracovat v týmových hrách a poznávat nové lidi se stejnými zájmy.

Otevřít dotazník

Technologie a vybavení

Herní zážitek ovlivňuje výkon počítače či konzole, monitor, ovladač, sluchátka i pohodlí při hraní.

Prohlédnout galerii

Jak projekt vznikl?

Gaming World vzniká v rámci semestrální práce. Cílem je procvičit tvorbu webových stránek, responzivní design a využití komponent Bootstrapu 5.

Technologie projektu

HTML zajišťuje strukturu stránek, CSS jejich vzhled a JavaScript interaktivní funkce. Bootstrap 5 poskytuje responzivní rozložení a připravené komponenty.

Projekt obsahuje navigaci, carousel, galerii, vyhledatelnou tabulku, formulář, záložky a modální okno.
